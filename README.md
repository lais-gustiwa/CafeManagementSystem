# Cafe Management System
Projek Pemrograman Berorientasi Objek.

## Fitur
- **Admin:** Login, Tambah Menu, Lihat Menu.
- **Kasir:** Login, Buat Pesanan, Proses Pembayaran.

## Cara Menjalankan Program
1. Pastikan Java Development Kit (JDK) versi 8 atau terbaru telah terinstall.
2. Clone repository ini: `git clone https://github.com/username/CafeManagementSystem-OOP.git`
3. Masuk ke direktori `src` dan compile: `javac CafeSystem.java`
4. Jalankan aplikasi: `java CafeSystem`
